# Archive Documentation Index

Archived plans, analyses, and operational guides live in this directory once the
active versions are superseded. Use this index to locate historical documents:

- `analysis-archived/` — Completed investigations and postmortems.
- `plans-completed-2025-11/` — Capability and roadmap plans that have shipped.
- `*_2025-11.md` files — Frozen snapshots of guides, status reports, and
  long-form write-ups from the November 2025 stabilization push.

When moving a document into the archive:
1. Add an `ARCHIVED` notice at the top of the file with the date.
2. Link to the replacement/active document if one exists.
3. Update any indexes (for example this file or the originating README) to
   reflect the new location.
4. Keep filenames date-stamped (`NAME-YYYY-MM.md`) for quick discovery.

Archived documents are read-only references meant to preserve context around
decisions that shaped the current App Monitor architecture.
