# Archived Analyses (November 2025 Snapshot)

This directory acts as a placeholder for the investigation reports that were
folded into the main `docs/analysis/` tree during the November 2025 cleanup.
The original files were removed from the repository, but multiple indexes still
reference `/docs/archive/analysis-archived/…`, so this README keeps those links
valid while pointing contributors to the current locations.

Historical analysis documents now live under:

- `docs/analysis/` — Active investigations and verification reports.
- `docs/archive/` — Completed plans (staged queue, deployment, PR workflow).

When new analyses are archived, create a dated Markdown file in this directory
with a short summary and a link to the active replacement so the link checker
and documentation index stay accurate.
