# Archived Analyses Index

The historical analysis documents referenced throughout the repository were
previously stored under `docs/archive/analysis-archived/`, but the directory was
removed during a cleanup pass which left several broken links. This lightweight
index restores the path so existing references continue to work and points
readers to the current source of truth.

## Where the content lives now

- **Active analyses** live in `docs/analysis/`.
- **Frozen November 2025 snapshots** were relocated to `docs/archive/` with the
  suffix `*-2025-11.md`. Use `git log -- docs/archive` to trace specific files.

If you are moving a document out of `docs/analysis/`, place the archived copy in
this directory (for example `STUCK_PRS_RESOLUTION-2025-11.md`) and update this
README so future link checks continue to pass.
