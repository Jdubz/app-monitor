# Completed Plans – November 2025

This directory restores the archived planning documents referenced throughout
the main documentation set. The original deep-dive decks were consolidated into
the current `docs/plans/` materials during the November 2025 stabilization
push, but the table-of-contents files still link to the archived filenames.

Each file in this folder now provides a concise historical summary plus a link
to the active document that superseded the plan. This keeps markdown link
checks green while still giving contributors the breadcrumbs they expect.

- `APP_MONITOR_CAPABILITY_ROADMAP-completed-2025-11.md` – Capability swimlane
  overview with references to the modern prioritized roadmap.
- `DEV_BOT_INTERACTIVE_SESSION_TAB-completed-2025-11.md` – Snapshot of the
  interactive session UI deliverable and pointers to current UI docs.

If additional archived plans resurface, add them here with a similar pointer so
cross-references remain accurate without duplicating entire specs.
