## Usage

### Submit Tasks to Queue
```bash
# Using the submit-and-monitor script
node submit-and-monitor-tasks.js dev-bots-tasks.json

# Or using the API
curl -X POST http://localhost:5000/api/dev-bots/tasks/bulk \
  -H "Content-Type: application/json" \
  -d @dev-bots-tasks.json
```

### Monitor Progress
```bash
# View task queue status
curl http://localhost:5000/api/dev-bots/queue/stats

# View active chains
curl http://localhost:5000/api/dev-bots/chains

# Monitor specific task
curl http://localhost:5000/api/dev-bots/tasks/{taskId}
```

### View in UI
1. Open http://localhost:5174
2. Navigate to "Dev-Bots" tab
3. View task queue and active chains
4. Monitor task execution in real-time
